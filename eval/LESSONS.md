# 하네스 개선 교훈

검증된 작업마다 실패 조건 → 수정 원칙 → 회귀 테스트를 1~3줄로 기록한다.
실패 후보의 교훈도 근거가 있을 때 기록한다. 최종 승인 diff에 포함한다.

- 2026-11-16: oracle의 누락 사례와 빈 검사는 통과가 아니다. 결과를 미검증으로 표시하고, 검사 실패는 종료 코드 1·검사 없음은 2로 반환한다. (이 후보 커밋에는 방어 테스트가 없다 — 별도 골든 하네스 변경 몫.)
- 2026-11-16: 팀컬러를 말한 스쿼드 요청에 메타 조회를 먼저 붙이거나, 수집 안 한 랭킹 순위를 이웃 랭커로 채웠다. 순위 한 명은 `get_ranker_squad(rank)` 한 번, 없으면 lineup 없이 없다고만 답하고 팀컬러가 있으면 `recommend_squad`만 부른다. `tests/test_ranker_squad.py`(수집한 순위의 선발 11명 일치, 0·미수집·20000위 무선발)와 공개 oracle이 방어한다.
